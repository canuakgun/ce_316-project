Integrated Assignment Environment

Automated grading for student code submissions

IAE automates the compile · run · compare pipeline for student programming assignments. It extracts student ZIP archives, compiles or interprets each submission using a configurable language setup, runs it against your test cases, and produces a colour-coded report.

All project data, configurations, and reports are stored locally in a SQLite database. No internet connection is required.

Quick start

  • i
    Create a configuration Go to Configuration → Manage Configurations. Set the compiler/interpreter path, source filename (e.g. main.c), and compile arguments. Built-in defaults for C, C++, Python 3, and Java are seeded on first launch.
  • ii
    Create a project Click + New in the sidebar. Enter a project name, choose a configuration, and browse to the folder containing student .zip files.
  • iii
    Add test cases Each test case defines the command-line arguments to pass and the expected stdout. At least one test case is required before running.
  • iv
    Run Select the project and click the floating Run grading pill. IAE extracts, compiles, and runs every submission. Results stream in live as each student is processed.
  • v
    Review & export Click any row in the results table to inspect the diff. Use File → Export CSV or Export HTML to save the report.

Configurations

A configuration describes how to compile and run submissions for one language. Open Configuration → Manage Configurations to create, edit, delete, import, or export configurations.

Compiler / interpretergcc · g++ · python3 · java
Compile arguments{SOURCE_FILE} -o {OUTPUT_PATH}
File to compilemain.c · Main.java · main.py
Executable patha.out · main · output.exe

Enable Interpreted for languages that do not need a separate compile step (Python, single-file Java). Configurations can be exported to .iaeconfig files and shared with colleagues.

Projects

A project ties together a configuration, a submissions directory, and a set of test cases. Select a project in the sidebar to load its details and latest report.

Use Edit to update the project name, configuration, submissions directory, or test cases. Use Delete to permanently remove the project and all its reports.

Running the grading pipeline

Click the floating Run grading pill (or press Ctrl R) to start. The pipeline runs on a background thread so the UI stays responsive.

  • i
    Extract All .zip files in the submissions directory are extracted to a temporary folder.
  • ii
    Compile For compiled languages, the source file is compiled. A non-zero exit code marks the submission COMPILE_ERROR.
  • iii
    Run & compare The program is executed for each test case. Output is compared with the expected value. A 10-second timeout is enforced per test case.
  • iv
    Report Results are saved to the database and displayed live in the results table.
A submission is marked SUCCESS only if every test case passes. The first failing case stops further execution for that student.

Results & statuses

Click any row in the results table to see the diff between actual and expected output.

PassedAll test cases passed.
Compile errorThe compiler exited with a non-zero code. Check the Error / Info column for details.
Runtime errorThe program crashed or exceeded the 10-second timeout.
Wrong outputThe program ran but its output did not match the expected output. Click the row to see the diff.
SkippedThe ZIP filename did not contain a valid 11-digit student ID, or extraction failed. Manual review required.

Exporting reports

After a run, use File → Export CSV or File → Export HTML to save the results.

The CSV contains one row per student: studentId, status, actualOutput, errorMessage, diffText.

The HTML file is self-contained with colour-coded status cells and can be opened in any browser.

ZIP naming convention

Each student ZIP must contain exactly one 11-digit sequence in its filename, which is used as the student ID.

20230602024.zipOK — student ID: 20230602024
John_20230602024_hw1.zipOK — student ID: 20230602024
homework.zipSkipped — no 11-digit ID found
20230602024_20230602025.zipSkipped — two IDs found, ambiguous
